# Enhanced ELM privacy policy

Effective date: 7 August 2026

Enhanced ELM is an independent browser extension that improves the local usability of ELM at `https://elm.edina.ac.uk/elm`. It is not affiliated with, endorsed by, or operated by The University of Edinburgh, EDINA, or ELM.

## Data the extension handles

Enhanced ELM can access visible ELM conversation content only to provide on-page functions selected by the user: visual layout, timeline navigation, math repair, formula/code/Markdown copy, Markdown export, explicit local snapshots, and explicit message bookmarks/notes.

Preferences, default-model preference, folders, tags, saved snapshots, bookmarks, and notes are stored only in the browser's extension-local storage on the user's device. A snapshot or bookmark may contain conversation text because the user deliberately requested that saved local function.

## Data sharing and retention

Enhanced ELM does not operate a server, use analytics, inject advertising, sell data, or transmit conversation content, saved snapshots, browser history, or personal data to the developer or to a third party.

Local data remains in the browser profile until the user removes the extension or clears the extension's data. The current version has no cloud sync or account.

## Permissions

- **storage** stores preferences and user-requested local workspace data.
- **https://elm.edina.ac.uk/*** limits the extension to ELM pages where it applies the visible features described above.

The extension requests no broad website access, identity, history, downloads, clipboard-read, or remote-code permission.
